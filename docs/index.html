01

What it actually does它到底做了什么

Four steps, then it gets out of the way.四个步骤，然后退到后台。

STEP 01

Ask the feed查询数据源

Resolves the current build for your channel from Chrome for Testing, or the vendor's own update service.从 Chrome for Testing 或厂商更新服务查询当前通道的最新版本。

STEP 02

Fetch it下载

Segmented download with resume. A direct ZIP instead of the 536 MB installer Google now serves.分段下载并支持续传。直接获取 ZIP，而不是 Google 现在提供的 536 MB 安装包。

STEP 03

Unpack beside it就地解压

Extracts into App\ next to the exe. Swap or delete the folder any time.解压到程序旁的 App\ 目录。可随时替换或删除。

STEP 04

Launch clean干净启动

Starts with its own profile directory. Optional GreenChrome / Chrome++ injection, off by default.使用独立配置目录启动。可选 GreenChrome / Chrome++ 注入，默认关闭。

03

What changed in 3.9.03.9.0 更新内容

This is the release that fixes current Chrome.本次更新修复了新版 Chrome 的兼容问题。

SourceChrome 158+

Chrome is resolved through the official Chrome for Testing feed. The old Omaha installer path is kept as a fallback.Chrome 改为通过官方 Chrome for Testing 数据源获取，旧的 Omaha 安装包方式保留为备用。

Install~170 MB

Direct ZIP extraction into the browser folder. No nested archive, no version-directory guessing — the step that kept failing.直接解压 ZIP 到浏览器目录。无需处理嵌套压缩包和版本目录，之前失败的正是在这一步。

Source codeFirst time

The complete AutoIt source ships in the repo. Upstream only ever published binaries.完整 AutoIt 源码随仓库发布。上游此前只提供编译好的程序。

BuildCI

Both architectures compile on every push through GitHub Actions, so a broken build cannot be released.每次推送都会通过 GitHub Actions 编译两种架构，避免发布无法构建的版本。

05

Build it yourself自行编译

One script downloads the AutoIt3 SDK, syntax-checks the source, compiles both architectures and packages the release archives.一个脚本即可下载 AutoIt3 SDK、检查语法、编译两种架构并打包发布文件。

Change anything in src/MyBrowser.au3 and the same pipeline rebuilds it.修改 src/MyBrowser.au3 后，同一流程即可重新编译。

# Windows, PowerShell 7
git clone https://github.com/drsamonline/MyChrome
cd MyChrome
./build/build.ps1
